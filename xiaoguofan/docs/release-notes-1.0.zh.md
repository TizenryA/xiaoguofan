# 渡鸦の小锅饭 1.0 更新说明

1.0 已经上线。你的密钥、账号和记录都保留着，聊天软件里的设置不用改。

## 变化

- **更快更稳**：所有账号由一个常驻的生成服务载入，不用再每次单独启动；开始回复更快，回复逐字返回。
- **还是只用你自己的账号**：每个请求只会用你名下的账号。一个账号额度用完会自动换你的另一个；全部用完时会直接告诉你大约几点恢复，不会借用别人的账号。
- **两条线路**（在“接入”页可以复制）：
  - 优化线路（国内推荐）：`https://xiaoguofanapi.tizenty.xyz/v1`，经洛杉矶中转，国内一般更快更稳。
  - 原始线路：`https://aistudio.tizenty.xyz/lite/v1`，直连本站服务器，海外网络用这个。
  - 同一把密钥两条都能用，随时可以换。
- **导入账号更简单**：可以直接粘贴 Cookie 字符串、Cookie-Editor 导出的 JSON、导出脚本的 .json 或 cookies.txt，也可以把文件拖进来。系统会自动向 Google 核对是谁的账号，不用手填邮箱。
- **自动识别套餐**：账号上会显示 Free / Pro / Ultra 等套餐（Google 还没告诉我们时显示“未识别”）。
- **首页改成“用了多少次”**：Google 没有公开额度上限，所以不再显示剩余额度，只统计本站成功回复的次数（每天北京时间 00:00 从零开始）。Google 真的说“用完”时会标出来，并显示预计恢复时间。
- **记录页更直观**：成功率、平均开始回复时间、Token 输入和输出、按小时或按天的用量；可以按结果筛选，也能导出 CSV。
- **防截断**：在“接入”页打开后，模型列表会多出带 [防截断] 的模型，能减少长回复被截断。

## 你需要做的

- 一般什么都不用做。
- 如果“我的账号”里某个账号显示错误（例如“Google 登录已失效”或“登录会话与所填 Google 邮箱不一致”），请按提示重新导出，再导入一次这个账号。
