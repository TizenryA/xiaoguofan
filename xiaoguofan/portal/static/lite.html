登录 Google / 打开 AI Studio ↗下载导入扩展
  1. 登录专用账号在新标签选择 Google 账号，确认 AI Studio 可用。
  2. 返回本页保持同一浏览器，点击本页标签上的扩展图标。
  3. 确认后上传填写 Google 邮箱与备注，授权读取后确认上传。

扩展可读取 HttpOnly 登录状态；普通网页和登录链接不能直接导出凭据。手机 Chrome 不支持桌面扩展，可用认证 JSON 上传。仅使用专用账号，避免多账号混淆。

如何获得认证文件？

使用 AIStudio2API 的本地登录流程获取认证状态文件（含 cookies 的 JSON），再上传。普通 Gemini API Key 不是此文件。也可使用下方浏览器扩展，读取 HttpOnly 登录状态并主动确认上传。

浏览器扩展导入

桌面 Chrome／Edge：下载解压 → 扩展管理开启开发者模式 → 加载已解压的扩展。登录专用 Google 账号，再在本门户标签点击扩展图标。检查目标和本人身份，授权读取后再次确认上传。手机 Chrome 不支持桌面扩展，仍可上传 JSON。

Google 会话是高敏感凭据，运营者可用它访问账号；仅使用专用账号和可信站点。请用独立浏览器配置，避免多账号状态混淆。上传成功不代表 Google 生成可用。
