      手机怎么上传？JSON 里需要什么？

      手机优先使用上方 Via 原生 Cookie 导入，不依赖油猴的 Cookie API。油猴 JSON 作为备选；无法完整读取 Cookie 时，可用电脑扩展或本地登录工具导出。不要编造或修改登录数据。

      文件可以是 {"cookies":[…],"origins":[]}，也可以把它放在 storage_state 字段里。新版脚本会把 Google 账号选择信息放进 storage_state；不要删掉。邮箱必须和文件绑定的账号一致，改邮箱不能切换账号。邮箱和备注在上传页填写；locale、timezone、fingerprint 是可选项，通常不用改。

      必须有 cookies 数组
      至少包含有效的 SAPISID、__Secure-1PAPISID、__Secure-3PAPISID。这是登录工具导出的原始数据，不是 Gemini API Key。

      每条 Cookie 的字段
      name 名称、value 原值、domain Google 域名、path 路径（必要项须适用根路径 /）。有效期用 expires 或 expirationDate，单位是秒；会话项可为 -1。httpOnly、secure 是开关，sameSite 是原来的限制类型，保持导出值即可。

      文件缺项或过期时，回电脑重新登录并导出。改到期时间不能让过期账号恢复。运营者能使用登录文件访问账号，所以请务必使用专用账号。
