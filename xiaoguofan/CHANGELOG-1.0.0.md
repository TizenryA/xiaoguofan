# 小锅饭 1.0.0（共享引擎）

- 一个常驻共享引擎替换每用户 worker：没有冷启动、没有闲置回收。账号仍各用各的：门户为每个请求附加可信账号范围，引擎强制只在该用户自己的账号中选号与切号，客户端无法伪造。
- 去掉冷却排队：429 时立即切到同一用户的其他账号；全部冷却时立即返回「北京时间 HH:MM（约 N 分钟后）恢复」和 `Retry-After`。
- 模型列表来自全站公共目录（SQLite 缓存 30 分钟），按用户账号套餐/引擎上报过滤，不再为看模型启动任何东西。
- 防截断拆为独立常驻服务 `anti/`（unix socket），门户连不上时自动退回旧的短进程方式并告警。
- P0：客户端断开（499）与参数错误（400）不再切换账号；非 SSE 流（含 Gemini 无 `alt=sse` 的流式数组）原样直通；静态资源带内容哈希长缓存；限速按真实访客 IP（只信任本机/配置的代理与 Cloudflare 边缘）；Discord 定期复核只影响网页登录，不再拦 API Key（管理员把人移出白名单仍会立即停用其 Key）；恢复请求体大小限制（管理接口 2MB，模型请求 64MB）。
- 每分钟次数限制改为可选（默认关闭），改用全站 48 / 每用户 4 的同时生成上限。
- 同一 Google 邮箱被不同用户导入时，按最早导入者归属，新导入返回 409，冲突在后台告警。
- 屏蔽引擎级共享对象接口（files、cachedContents、videos、operations 等）；Responses 续写只允许本人发起的会话。
- 数据库只新增表，附 `scripts/migrate_shared_engine.py`（备份 + 行数核对 + 重复邮箱预检，`--check` 只读）。
- 新增 DMIT 入口 Caddy 配置与部署/回滚文档（`docs/共享引擎部署与回滚.md`）。
- 用户端只保留「首页 / 记录 / 我的账号 / 接入」：首页显示一句话服务状态和今日额度；我的账号合并上传入口并显示每个账号的人话状态（可用、额度用完会恢复、登录失效等）；接入页放 Base URL、密钥和防截断开关。去掉账号池、通道、实时负载等内部术语。
- 管理后台新增「实时」页（管理员默认首页）：生成服务在线状态、正在生成/排队、近 5 分钟成功/额度用完/失败/取消、项目内存与 CPU、账号状态分布、告警列表（可标记已处理）、账号 × 模型健康度矩阵（取消与格式错误不计入账号失败），以及「重新同步账号」「重启生成服务」。
- 站点设置改为「全站同时生成上限 / 每用户同时生成上限 / 每分钟次数限制（可选）」。
